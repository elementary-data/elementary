### Why choose Elementary Cloud?

<AccordionGroup>
  <Accordion title="Built for data developers" icon="code" iconType="solid">
    Elementary configuration can be managed as code in your dbt project, and Elementary Cloud syncs configuration changes from the UI back to your code repository. Cloud tests are configured in the UI with no code required.

    You won't need to duplicate configuration - all your existing tests, owners, tags, and descriptions are leveraged.

  </Accordion>

  <Accordion title="Secure by design" icon="lock" iconType="solid">
    Elementary Cloud can't access your data.

    The dbt package creates a schema for logs, results and metadata, and Elementary only requires access to the Elementary schema.

    [Read about Security and Privacy >>>](/cloud/general/security-and-privacy)

  </Accordion>

  <Accordion title="Native to the modern data stack" icon="cube">
    Connect your data warehouse to get started - Elementary reads warehouse metadata and runs cloud tests without a dbt project. If you use dbt, the Elementary dbt package automatically collects your test results and artifacts, and your dbt-based configuration stays managed in code.

    Elementary works across your stack - warehouse, dbt project, code repository, and BI - so all your tests and results live in one dashboard and interface.

  </Accordion>

  <Accordion title="Cloud only features and integrations" icon="stars" iconType="solid">

    - Automated volume, freshness and schema monitoring
    - Column level lineage
    - Automated lineage to BI tools dashboards
    - Multiple environments
    - Test management
    - Data catalog
    - Webhook triggered syncs
    - And more...
  </Accordion>

### How does it work?

The Elementary dbt package runs as part of your dbt invocations.
The package collects and stores data such as run results, test results, anomaly detection results and more.

This data is saved to an Elementary schema in the DWH.
The Elementary cloud service requires access only to this schema, to connect and generates a report UI and Slack alerts.
