<Note>
SQL-based cloud tests read table data, so they need **data access** for the environment's warehouse connection. Data access is enabled in one of two ways:

- Elementary enables data access on the warehouse connection. Contact the Elementary team to turn it on.
- You connect an [Elementary Runtime](/cloud/features/elementary-runtime) to the warehouse connection.

Until data access is available, these tests are hidden from the test catalog.
</Note>
