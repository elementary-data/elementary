## Install Elementary CLI

The installation depends on the dbt version your project runs on.

### dbt v2 (Fusion)

Install the CLI without any extra:

```shell
pip install elementary-data
```

Then install dbt v2 itself (the `dbt` or `dbt-oss` package) by following [dbt's installation guide](https://docs.getdbt.com/docs/local/install-dbt). dbt v2 has adapters built in, so no warehouse-specific package is needed.

### dbt Core 1.x

Install the CLI with the `dbt1-` extra matching your platform (no need to run all):

```shell
pip install 'elementary-data[dbt1-snowflake]'
pip install 'elementary-data[dbt1-bigquery]'
pip install 'elementary-data[dbt1-redshift]'
pip install 'elementary-data[dbt1-databricks]'
pip install 'elementary-data[dbt1-athena]'
pip install 'elementary-data[dbt1-trino]'
pip install 'elementary-data[dbt1-clickhouse]'
pip install 'elementary-data[dbt1-duckdb]'
pip install 'elementary-data[dbt1-dremio]'
pip install 'elementary-data[dbt1-spark]'
pip install 'elementary-data[dbt1-postgres]'
```

The extra installs dbt Core 1.x and the warehouse adapter alongside the CLI. The legacy extras without the `dbt1-` prefix (e.g. `elementary-data[snowflake]`) are still supported and install the same packages.

For Vertica, install `elementary-data` and the `dbt-vertica` adapter directly:

```shell
pip install elementary-data dbt-vertica
```

Run `edr --help` in order to ensure the installation was successful.

If you're receiving `command not found: edr` please check our [troubleshooting guide](/oss/general/troubleshooting).
