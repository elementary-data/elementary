Elementary pushes data health scores and open incidents onto matching Atlan assets as custom metadata.
Anyone who works in Atlan can see whether a table is healthy without leaving the catalog.

<Note>
  Atlan is an outbound catalog export, configured per environment. It is separate from **Metadata Layer** (Glue / BigLake), which pulls warehouse metadata into Elementary.
</Note>

## How it works

1. You connect an Atlan tenant to an Elementary environment with a base URL and API token.
2. A regular sync writes health scores, incident links, and badges onto matching Atlan tables.

## Enabling Atlan

<Info>
  Connecting Atlan requires permission to edit integrations in Elementary.
</Info>

<Steps>
  <Step title="Create an Atlan API token">
    In Atlan, create a persona (or reuse one) and generate an API token for Elementary.

    Grant that persona:

    - Assets: Read (search)
    - Assets: Update
    - Governance: Update custom metadata values
    - Permission to create and update badges

    Without write access to custom metadata and badges, the connection can succeed and the export will still fail.
  </Step>
  <Step title="Add the connection in Elementary">
    Go to **Settings → Environments**, select the environment, and click **Connect** on the **Data catalog** card.

    <Frame caption="Data catalog integration in environment settings">
      <img
        src="/pics/cloud/atlan-data-catalog-connect.png"
        alt="Data catalog integration in environment settings"
      />
    </Frame>

    In **Connect Atlan**, paste the **Atlan base URL** (for example `https://your-company.atlan.com`) and **API token**. Click **Test connection**, then **Connect**.

    Each environment can have one Atlan connection.
  </Step>
</Steps>

To replace an expired token, open **Edit Atlan connection**, paste the new token, test, and save. Disconnecting is not required.

If you install Elementary from the Atlan marketplace, generate an [account token](https://app.elementary-data.com/settings/account-tokens) and use that in Atlan. The token is shown once; revoke or rotate it from the same page.
